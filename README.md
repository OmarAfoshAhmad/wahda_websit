# منظومة رعاية مصرف الوحدة

هذا المستودع الخاص هو خط الصيانة المعزول للنسخة المنشورة الخاصة بمصرف الوحدة، والمخصصة للكشوف والأدوية وفق آلية السقف القديمة.

## خط الأساس

- المصدر: commit `852162c5a69a23d391739dd1e11307664b7e3a85`
- الرسالة: `test deploy before v6`
- تاريخ المصدر: `2026-05-07`
- لا يحتوي المستودع على قاعدة بيانات الإنتاج أو ملفات البيئة أو النسخ الاحتياطية أو تقارير المستفيدين.

القوالب العامة الفارغة اللازمة للاستيراد محفوظة داخل `public/`، أما ملفات Excel وCSV التشغيلية فهي مستبعدة من Git.

## قواعد الصيانة والنشر

1. كل تحسين يبدأ في فرع مستقل ويراجع قبل دمجه في `main`.
2. لا تدمج تغييرات النسخة متعددة الخدمات مباشرة في هذا المستودع؛ تنقل التغييرات المطلوبة يدويًا وبنطاق واضح.
3. لا تشغّل `prisma db push` أو أوامر إعادة الضبط أو seed على قاعدة بيانات الإنتاج.
4. قبل أي نشر: خذ نسخة احتياطية خارج مجلد التطبيق، اختبر الاستعادة، ثم استخدم migrations مراجعة مع `prisma migrate deploy` فقط عند الحاجة.
5. ملفات `.env` تبقى على الخادم ولا ترفع إلى GitHub.

## التشغيل المحلي

انسخ `.env.example` إلى `.env` وضع قيم بيئة تطوير غير إنتاجية، ثم:

```bash
npm ci
npx prisma generate
npm run dev
```

سيتم تطوير تحسينات الصلاحيات في فرع مستقل من هذا الخط، من دون تغيير بيانات النسخة المنشورة حتى تتم مراجعة التعديلات واختبارها.
